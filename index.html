The Science

How AI Watermarks Work — And How We Remove Them

Modern LLM watermarks hide signals in two distinct layers. We attack both.

Layer A
👁️

Invisible Unicode Marks

AI systems inject invisible characters into text — zero-width spaces, bidi controls, variation selectors, and Unicode tag sequences — completely invisible to readers but machine-readable by detectors.

U+200B ZWSPU+200C ZWNJU+FEFF BOMBidi controlsTag chars
Removable:✅ Deterministic
Layer B
📊

Statistical Token Sampling

Techniques like Google's SynthID-Text bias which words are chosen at generation time. The signal lives in the vocabulary distribution — no character is visibly changed, making it far harder to detect.

SynthID-TextKirchenbauerToken biasSampling shift
Removable via:⚡ Rewrite (best-effort)
Files
📄

File Metadata & C2PA

Images, PDFs, and documents carry AI provenance inside EXIF tags, XMP blocks, C2PA manifests, and document properties — all invisible until you inspect the raw bytes.

C2PAEXIFXMPDocPropsJSON-LD
Removable:✅ 8+ file types

Capabilities

Everything You Need for AI Text Hygiene

🔒

100% Private

All processing runs locally in JavaScript. Your text is never uploaded to any server. Zero telemetry, zero logs.

🔬

Deep Unicode Scan

Detects 70+ suspicious codepoints: ZWSP, ZWNJ, ZWJ, BOM, bidi controls, variation selectors, and Unicode tag chars (U+E0001–U+E007F).

🤖

Multi-Vendor Coverage

Targets provenance marks from Anthropic Claude, Google Gemini / SynthID-Text, OpenAI GPT, and Kirchenbauer-style open-LLM marks.

📁

8+ File Formats

CLI scripts clean PNG, JPEG, SVG, PDF, DOCX, ODT, HTML, and Markdown — stripping C2PA manifests, EXIF data, and document properties.

✍️

Layer B Rewrite

Optional statistical-mark attack via heavy paraphrase. Run locally with Ollama or any OpenAI-compatible endpoint. API keys are env-only.

⚡

Open Source & Free

MIT licensed. Python 3.10+ stdlib only for scripts — no heavy dependencies. Optionally integrates c2patool and exiftool.
